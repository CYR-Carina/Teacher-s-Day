# 教师节彩蛋页 · 信息与通信学院

教师节当天，老师扫码即可打开的祝福彩蛋页：满屏飘落"老师教师节快乐"+ 星星，
点击任意位置有粒子惊喜，点"为老师放一场烟花"触发烟花秀。

## 在线地址

部署到 GitHub Pages 后即为：

```
https://<你的GitHub用户名>.github.io/teacher-day-gh/
```

用任意二维码工具把上面的链接转成二维码，打印张贴在公告栏或发到群里即可。

## 目录结构

```
teacher-day-gh/
├── index.html         # 彩蛋页（Pages 首页，二维码指向这里）
└── teacher-day.html   # 同名副本，兼容直接访问
```

## 本地预览

双击 `index.html` 即可在浏览器打开预览。

## 修改文案

打开 `index.html`，搜索 `<div class="card">`，修改其中的文字（标题、寄语、落款等），
保存后重新提交推送即可。
